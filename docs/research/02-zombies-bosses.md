# 02 — CSO「災厄之章」(Zombie Scenario) AI 殭屍與 Boss 研究

> **目的**：為手機多人合作割草射擊遊戲（mobile co-op horde shooter）設計**原創**敵人。本文拆解 Counter-Strike Online（CSO，Nexon；台灣由遊戲橘子代理，台服模式名「災厄之章」，韓服「좀비 시나리오」，中國「大災變」）的殭屍與 Boss，借鏡機制與節奏，**不照抄造型、名稱與劇情**。
> **調查日期**：2026-10-12
> **主要資料**：CSO Fandom Wiki（英文版、繁中版）、namu.wiki（韓文，內容最詳細）、台灣遊戲新聞、Steam 社群（見文末來源）。
> **標記說明**：⚠️ = 來源互相矛盾、資料過舊或未經證實；（推測）= 本文作者的推論，不是官方資料。
> **數值說明**：HP 用韓服慣用的「K」表示（1,000K = 100 萬）。官方從未完整公開 HP，本文列出的數字都來自 wiki 玩家整理，且會隨難度與版本變動。

## 0. 重點摘要（TL;DR）

1. **雜兵設計靠「職能」區分，不靠數值**：一般型、速度型、坦克型、補師（巫毒）、遮蔽型（黑煙）、長手突刺、死亡自爆、低矮快速的狗、爬牆型、遠程丟彈型，各自逼玩家做出不同反應。高難度再加上「換色變體」、「冠軍殭屍」和「菁英怪詞綴」三層。
2. **Boss 的看點在場地機關與階段變化**，HP 數字本身不是重點。最常被記住的設計有：
   - 必須去轉的閥門、雷達、加農砲、無線電
   - 打到一定血量就換形態，或長出新武器
   - 弱點只在特定時機打開
   - 被吞進肚子後要在裡面炸開才能出來
   - 雙 Boss 要平衡兩邊血量，否則較弱的一方會狂暴
   - 160 公尺高的巨型機甲，偽裝成廢棄大樓登場
3. **玩家最常抱怨的幾件事**：
   - 打掉玩家手上武器（disarm）
   - 無法閃避的即死招
   - 血量太厚又一直無敵，戰鬥被拖長（HP sponge、burrow、回血）
   - 依賴課金武器，火力通膨後舊 Boss 幾秒就死
   - 生存圖要長時間等待
   - Bug 讓 Boss 卡住或不出現
4. **手機版要特別調整的地方**：
   - 「繳械」改成短暫卡彈
   - 「即死」改成倒地後可救
   - 「蹲下躲招」改成翻滾無敵幀
   - 所有招式都要有地面標示、語音提示，並且能閃避（不能穿牆打人）
   - 共同破解的機關一定要有單人可完成的替代方案

## 1. 模式速覽

### 1.1 玩法類型（台服前綴）
| 類型 | 說明 | 例 |
|---|---|---|
| 生存 Survival | 守住據點撐過回合；早期有 20–50 回合，2015 年後改為 5 回合 | Lost City、Double Gate、Trap、Culvert |
| 追蹤 Pursuit | 推進路線，拆紅色障礙物、按 E 啟動裝置，最後進 Boss 房 | 主線大部分章節 |
| 防禦 Defense | 保護中央電腦或貨物 | Threat、Upcoming Threat |
| 擊破／恐懼之間 | 不換回合，直接打多階段 Boss | Panic Room |
| 殲滅 Annihilation | Boss Rush，每回合一個 Boss（通常 R1 是 Juggernaut） | Nightmare、Poisoning、Illusion、Madness |
| 襲擊 Raid | 模擬或復活歷代 Boss 連戰 | Collapse、Oblivion、Forest Keeper、Electron、Void Zone |
| 護送 Convoy | 跟車推進，殭屍靠近時車會停下 | Convoy（S9 支線） |

### 1.2 系統重點
- 最多 10 人。地圖中有商店區可買武器。打中或擊殺殭屍都會給錢和經驗，升級時自動提升 **HP／攻擊／速度／護甲／彈藥**：
  - Lv1：HP 100、攻擊 100%、移速 250 u/s
  - Lv30：HP 1200、攻擊 580%、移速 300 u/s
  - 衝刺上限 390 u/s
- **難度**：簡單／普通／困難／非常困難／地獄／烈獄（불지옥）／無限地獄。
  - 普通以上會出現**菁英怪**，困難以上出現**冠軍殭屍**。
  - 難度越高，建築物和 Boss 的 HP 越厚。
  - 非常困難以上不能丟武器給隊友。
- **2018 年**：困難 3 以上，部分 Boss 技能變成「即死」，同時推出對應的「抵抗道具」。**2021 年**：刪除部分 Boss 的即死判定。
- **2026-05-28 韓服平衡測試**：
  - 怪物攻擊力與 HP 上調，理由是玩家武器通膨後怪物數值多年沒動
  - 困難以上的復活冷卻從 10 分鐘縮短到 30 秒
  - Boss 寶箱逾時會自動拾取
- **NPC 無線電預警**：Soy、Jim、Gerard、Lucia 等 NPC 會在 Boss 放大招前喊話。從 Dione 開始，這成為固定的預兆設計。

## 2. 一般 NPC 殭屍

### 2.0 相對尺度說明
- 官方沒有公開劇情模式雜兵的 HP，下表的 HP 與速度是**相對等級**，以 Regular 為 1 做比較（推測）。速度的參考值取自 namu 的「可遊玩殭屍」移速（站立 u/s）：Regular 290、Light 310、Heavy 265、Psycho 290、Voodoo 280、Sting Finger 300、Venom Guard 265、Deimos 290、Ganymede 275。對照玩家劇情模式的移速 250→300（滿級）。
- 已知的具體數值：
  - Deimos：4,000（host）／8,000（origin）
  - Ganymede：16,000（中頭目）／100,000（Boss Rush R2）
  - Juggernaut：35,000（中頭目）／400–450K（Boss Rush R1；Madness 版 600K）
  - Hound：改版前最大 HP 900 ⚠️

### 2.3 冠軍殭屍 Champion Zombie（2016 年起，困難以上）
- 外觀是原本的殭屍換成高彩度顏色，被玩家戲稱「像軟糖或紅綠燈」。
- 難度越高，HP、攻擊、出現頻率和數量都越高。很多人覺得它們**比 Boss 還難纏**。
- 2016 年同時改成「打中就給錢和經驗」，就是為了配合冠軍殭屍。

| 冠軍 | 顏色 | 專長 |
|---|---|---|
| Regular | 紅 | **遠程投彈**。丟得很準、引信長，困難 7 無護甲時一顆扣 250–300。常站著不動；生存圖躲在建築裡仍會被炸到 |
| Light | 紅 | 近戰。等於強化版 Stalker，快、痛、比較耐打；站著時會低頭，讓爆頭線變低 |
| Heavy | 紫 | 坦克。HP 接近 Juggernaut，但比 Juggernaut 小又快，很難集火 |
| Voodoo | 綠 | 治療。補量非常大，會讓其他冠軍很難死，必須優先擊殺 |
| Venom Guard | 綠 | 自爆。速度快又耐打，追上來會打人，打死它又會被炸 |

### 2.4 菁英怪 Elite Monster（2021 年起，普通以上）
- 外觀是**縮小的紫色 Juggernaut**，能鑽進玩家躲的地方。擊殺後掉落 Add-on 與 Parts（裝備養成素材）。
- 生成時隨機帶詞綴，難度越高詞綴越多、越強：

| 詞綴 | 效果 |
|---|---|
| Fast | 移動和攻擊變快 |
| Altered ego／分身 | 一次出現 2 隻以上，難度越高越多 |
| Attack up | 攻擊提升 |
| Fireball | 定時丟**可穿牆**的火球 |
| Cold explosion | 冰爆，造成傷害並緩速 |
| Firewall | 在隨機位置生成火牆 |
| Thunderbolt | 在隨機位置落雷 |
| Invincibility | 每隔一段時間無敵 |
| Stamina up | HP 提升 |
| Auto-heal | 持續回血，一段時間沒受傷會回更多 |
| Double sidedness | 輪流切換「怕槍、抗近戰」與「抗槍、怕近戰」 |
| Black hole | 把玩家吸過去並造成傷害 |
| Spider web | 所有玩家緩速 |
| Teleport | 定期瞬移到玩家身邊（namu），容易擋路 |

- 2023 年多次調整出現機率與強度，並在「不能用武器的區域」停止生成。
- namu 提到：在大幅削弱之前，烈獄難度單人遇到「無敵＋分身＋攻擊提升」組合時，只能逃跑。

## 3. Boss 詳解

> 每個 Boss 依序列出：**登場 → 外觀與體型 → HP → 招式與預兆 → 弱點 → 階段 → 場地機制 → 記憶點與抱怨 → 💡原創設計構想**。

### 3.1 Prototype Phobos（台：雷比亞）— S1 Last Clue
- **登場**：Last Clue R2；Nightmare R3；Zombie Shelter 的 Desert Plant 和 Hell Ride；新手教學模式。
- **外觀與體型**：沒有眼睛（推測靠聽覺），腿很長，皮膚偏藍。左臂上的利爪其實是**另一隻寄生生物**，Boss 死後它會掉下來不動。巨大，靠近時畫面會震動。
- **HP**：未公開。剛推出時，10 人滿裝備（MG3、M134）要打 20–30 分鐘，普通玩家的房間甚至超過 1 小時。現在高手幾十秒就能打掉（火力通膨）。
- **招式**：

  | 招式 | 預兆 | 效果 |
  |---|---|---|
  | 揮爪 | 鎖定一人後逼近 | 傷害不高，但場地小，躲不掉 |
  | 衝擊波 | 左臂聚氣後砸地 | 小傷害，**強制繳械** |
  | Mahadash 衝刺 | 壓低身體，然後跳出去 | 高傷害或即死、擊飛加墜落傷害；可能連撞兩下，也可能途中改撞別人 |

- **弱點**：頭部。
- **階段**：沒有。開打約 1 分鐘後，增援殭屍湧入（Stalker、Thrower 等強化殭屍，後期還有 Juggernaut）。
- **場地**：狹窄 Boss 房，沒什麼空間清小怪。對策是全隊分散，避免被一次衝刺撞到多人。
- **記憶點與抱怨**：第一個 Boss，招式單調。繳械衝擊波很討人厭（JANUS 系武器的蓄能會被重置）。曾有 Boss 不出現的 Bug。
- 💡 **原創構想「迴聲獵手」**：三足、細高的身形（和 Phobos 的兩足長腿區分）。
  - 頭部是一圈聲納鰭，**被「噪音值」最高的玩家吸引**（持續開火的人噪音最高），鼓勵輪流開火、輪流躲避。
  - 衝刺前地面出現**聲波漣漪**作為預兆。
  - 繳械改成「耳鳴」，2 秒內射速減半。

### 3.2 Siege Type Phobos（台：狂暴雷比亞）— S1 Chaos
- **登場**：Chaos 最終戰；Nightmare R4；Collapse 等。
- **外觀**：紫色版 Phobos，設定上是戰鬥型。
- **招式**：和 Prototype 相同，衝擊波傷害較高。
- **場地與機制**：
  - 戰鬥中途會出現 Voodoo 殭屍，**牠們靠近 Boss 就會幫 Boss 回血**，必須優先擊殺。
  - Chaos 的路線會依多數人的選擇改變，總共 4–7 回合。
- **記憶點**：很早就做出「補師小怪＋Boss」的組合。曾有用錘子把 Boss 擊退回出生點的 Bug。
- 💡 **原創構想**：Boss 背上有「補給槽」，由「搬運工」小怪送回能量球來補。玩家可以**攔截能量球**，打爆時對周圍小怪造成範圍傷害，把「保護 Boss」轉成玩家的機會。

### 3.3 Oberon（台：阿比隆）— S1 Dead End
- **登場**：Dead End R2；Nightmare R5；Collapse；New Zombie Shelter。
- **外觀**：極度肥胖的**獨眼**灰色巨怪，背上有令人不舒服的孔洞。Rex 的三大生物兵器之一，設定上吸收了 Siege Dione。
- **HP**：未公開。最大傷害約 100–300，狂暴後可到 500（Fandom 舊資料 ⚠️）。
- **招式**：

  | 招式 | 預兆 | 效果 |
  |---|---|---|
  | 拳擊或爪擊 | 走近 | 移動不慢，幾乎甩不掉 |
  | 高跳砸地 | 跳到約 4–5 層樓高 | 落點下方的人**直接死亡**，周圍有小範圍濺射 |
  | **黑洞** | 腳下出現黑色漩渦 | 把玩家吸過去，接著**旋風斬**。跳起來會被吸得更快；殭屍不會被吸，可以拿來當支撐 |
  | **炸彈拋射** | 趴下 | 背孔噴出大量刺球炸彈，**追蹤玩家並在空中爆炸**（等同打頭），是最致命的招式 |
  | 衝擊波 | 拳頭砸地 | 繳械 |

- **階段**：HP 降到 50% 時跳出警告訊息，Boss 嚎叫並**長出巨爪**，所有近戰傷害 +50%。這是 Rex 系列 Boss 中唯一的狂暴。
- **場地**：場地很寬，小怪比 Phobos 少。Bug：有時會跳到場外，炸彈也丟到場外。
- **記憶點**：魔法般的招式（黑洞、背部炸彈），是「生物兵器卻像惡魔」的反差。在 Zombie Shelter 模式中被戲稱為「沙包」。
- 💡 **原創構想「鐘樓胖子」**：低矮橫向的蟹步體型（和直立獨眼巨人區分），背上是**管風琴狀的孢子砲管**。
  - 「吸引」改成**磁力錨**：Boss 把錨插進地面，拉近玩家；玩家可以射斷錨鏈。
  - 50% 時外殼裂開，露出刀狀骨刺，同時弱點外露。

### 3.4 Dione（台：麥瑪西）— S2 Toxicity
- **登場**：Toxicity R2；Culvert R4–8（騷擾）；Poisoning R3；Collapse。
- **外觀**：類似深海魚的爬蟲，**6 隻眼**、暴牙、有鰓，**胸口有一顆血塊腫瘤**。速度極快，是唯一逃走的 Rex 生物兵器。
- **HP**：未公開。被打到 0 時會休息（**無敵**）然後逃走，是第一個「打不死、會逃」的 Boss。
- **招式**（NPC Soy 會預告下一招）：

  | 招式 | 預兆 | 效果 |
  |---|---|---|
  | 抓擊 | 近身 | 攻速很快 |
  | 旋轉 | — | 360° 範圍，**繳械** |
  | **翻滾** | 捲成一團，準備時間較長 | 鎖定一人，**直接撞死** |
  | **觸手** | 雙手砸地，地上出現**黑點** | 觸手從地面竄出，把人頂上天（觸手傷害加墜落傷害）。**蹲下可免疫**。一般版：正前方 3 條。強力版：連砸 7 下，延遲後隨機大範圍爆發。狂暴後改成**螺旋形**，背後也不安全 |
  | **毒吐息** | **搖頭呻吟約 3–4 秒** | 扇形毒霧，狂暴前約 130°、狂暴後 180°；緩速並持續扣血（30／50 每秒）；時機抓對可跳過 |

- **弱點**：**胸口腫瘤**，幾乎是唯一能吃滿傷害的部位。
- **階段**：HP 50% 時狂暴，觸手的分布方式改變，毒吐息範圍變大。
- **場地**：叢林，有大石頭可以站上去躲小怪。地圖中有 TNT 和按鈕等互動元素。
- **記憶點**：「跨章節宿敵」：Dione → Siege Dione → 結繭 → Angra，串起整個第二季（4 份觀察日誌）。語音預告讓預兆系統成形。
- 💡 **原創構想「蛻殼者」**：犰狳加蜈蚣的輪廓，每次遭遇都**蛻一層殼**進化，作為跨章節宿敵。
  - 地刺攻擊前地面出現**裂紋網**預警。
  - 翻滾改成「鑽地衝浪」，路徑由地面隆起的直線顯示。
  - 噴吐前胸殼張開露出發光核心，等於「出大招時弱點也打開」，給予冒險輸出的回報。

### 3.5 Siege Type Dione — S2 Culvert／Decoy
- **外觀**：紫色皮膚、紅色背刺，腫瘤變成綠色毒囊（進化後）。
- **機制**：在 Culvert（生存，5 回合×3 分鐘）中**無法被傷害**。會從暗處的管道滾出來撞人（即死），從上層噴毒、用觸手攻擊，然後撤退。是唯一出現在生存圖的 Boss。在 Decoy 中只有逃跑的過場。
- **抱怨**：Culvert 是生存圖而不是大家喜歡的追蹤圖，結果變成「沒人想玩的地圖」。早期還有「打死騷擾的 Dione 就直接過關」的 Bug。
- 💡 **原創構想**：生存圖中打不死的**環境威脅**。玩家可以開「探照燈」把它逼退，給防守方「我能應對」的感覺，而不是只能被動挨打。

### 3.6 Revenant（台：炎魔）— S2 Decoy
- **登場**：Decoy 最終戰；Poisoning R4；Collapse；Desert Plant；Hell Ride（主 Boss）。
- **外觀**：火焰屬性的裝甲蠻漢（Deimos 和 Ganymede 系的自然變異），**體型比前幾隻小**。登場時先擊落 Delta 隊的直升機，接著**做暖身操**（開合跳），這段時間無敵。
- **HP**：普通難度約 **1,300K**（namu）。
- **招式**：

  | 招式 | 預兆 | 效果 |
  |---|---|---|
  | 爪擊 | 壓低身體 | 攻擊距離比外表長；地獄難度下連普攻都能打穿護甲 |
  | 衝刺 | — | 高傷害或即死，**會輾過擋路的小怪**，所以不能拿小怪當肉盾 |
  | 火球 | 雙手生成火球 | 隨機鎖定一人，落點範圍傷害加燃燒；平常 2 顆，著火狀態 4 顆 |
  | Inferno | — | 周圍連環爆炸，連續繳械 |
  | **Hellfire Rain／Firestorm** | **Soy 警告**，四角的冷卻管閥之一亮起 | 3 秒內**按 E 轉開閥門**就能化解（化解前 Boss 無敵）。失敗的話，全場地面變紅並降下火雨；只有機槍台的屋簷下比較安全 |
  | **著火（狂暴）** | HP ≤ 50% | 全身起火，靠近會持續燒傷，**受到的傷害減半** |

- **弱點**：⚠️ Fandom 說胸口發光的「王冠」區塊受傷較多，namu 說沒有弱點。**裝甲對穿透屬性免疫**，SKULL 系穿透武器沒用。
- **場地**：四角各有冷卻管，兩側各有固定式機槍（M2）。轉開閥門後 Boss 防禦下降。
- **記憶點與抱怨**：「場地機關取消大招」的經典範例。當年被認為比 Angra 還難。抱怨包括：登場暖身時間太長、Decoy 前段的裝置等待時間長（2022 年才縮短）、閥門有時按不動。
- 💡 **原創構想「雷鳴監工」**：改成電屬性。蓄電大招要玩家**插下避雷針**（分散在場地各處的互動點）來接地化解。50% 後進入「過載」：身邊有電場，近戰距離會被電，但**被避雷針擊中時會進入短暫昏迷**，讓機關同時具備攻防兩種用途。

### 3.7 Angra（台：安格拉）— S2 Angra Nest
- **登場**：Angra Nest R2；Poisoning R5；Desert Plant（第 7 天起飛到據點空投深藍色強化殭屍）；Zombie Giant 模式可操作。
- **外觀**：Dione 結繭後**完全變態**成的**有翼歐洲龍**。眼睛從 6 隻減為 2 隻，鰓消失。是**第一個會飛的 Boss**。
- **HP**：極高（Fandom：「extreme health」），數值未公開。**HP 低於 50% 時受到的傷害×2**（namu），所以有人覺得比 Revenant 好打。
- **招式**：

  | 招式 | 預兆 | 效果 |
  |---|---|---|
  | 觸手 | 混用一般版和狂暴版 | 同 Dione，但更痛 |
  | 毒吐息 | 地面上會先挺起身體，鎖定目標後慢慢轉向；空中會先停頓 | 沒有 NPC 預警、預兆很短；繞著 Boss 跑可以躲 |
  | **落地地震** | 降落 | **全場只要腳踩地面就會繳械和硬直**，落地瞬間跳起才能避免；被它直接壓到會死 |
  | **毒牆＋翼風** | Boss 在場中央吐出一道毒牆後飛離 | 場上兩個角落的**兩台雷達必須同時啟動**，才看得到 Boss 從哪裡飛回來；回來時用翼風把毒牆擴大，碰到即死。Boss 越殘血，循環間隔越短 |
  | 預判觸手 | Soy 警告 | 觸手會**預測你的走位**連續追打；站到雷達上、蹲下或繞圈可以躲 |

- **弱點**：全身都吃傷害，但一直在飛，實際打起來不容易。
- **場地**：2 挺 M2 重機槍、2 台雷達、毒水池。
- **記憶點與抱怨**：「宿敵最終形態」加上飛行，非常有史詩感。**需要兩名玩家同步操作**的機關是很好的合作設計，但隨機路人房常因此團滅。落地繳械很惡名昭彰。
- 💡 **原創構想「孢翼女王」**：巨型飛蛾或魟魚的輪廓（不用龍）。
  - 會灑下孢子簾幕分割戰場。
  - 兩座「信標」要由兩名玩家同時啟動；單人時可以改成一座、計時加長。
  - 落地衝擊改成**手機翻滾無敵幀**來閃避，取消「跳躍免疫」。

### 3.14 Neid & Zavist（엔비 자매；台：雙刃娜吉＆重砲菲納絲）— S4 Envy Mask
- **登場**：Envy Mask R2；Madness R4（HP 減半）；Paranoia（中頭目，兩人分開出現：Zavist 先，倒下後才換 Neid）；Collapse。
- **外觀**：Rex 的兩個女兒，超級士兵計畫的「成功作」，身高約為人類的 2 倍。**Neid** 主打速度，拿武士刀；**Zavist** 主打力量，穿裝甲。兩人**互相憎恨**。是第一批會說話的 Boss，也是第一批女性 Boss。
- **HP**：普通難度各約 **1,600K**（合計 3,200K，namu 註腳 ⚠️）。
- **核心機制**：
  - **血量平衡**：兩人 HP 差太多時，**血少的那個會狂暴，受到的傷害減半**。必須平均輸出。
  - 兩人都剩 30% 以下時都會狂暴；其中一人死亡，另一人立刻狂暴。
  - **互鬥**：兩人衝到場中央對打，產生衝擊波把玩家推到外圍，**場上小怪全死**（玩家賺不到錢）。
  - **引開仇恨**：NPC 會叫你去攻擊她們。兩名被盯上的玩家要**往相反方向跑**把兩人拉開，否則會再次相撞，發出強力衝擊波。
  - 預兆：Neid 在攻擊、Zavist 卻只是走路 = 即將互鬥。
- **招式**：
  - Zavist：跳躍砸地（砸地 2 下後撲向目標；繞到她背後可以解除鎖定）、**鎖定追蹤的旋風**（幾乎躲不掉）、**舉坦克砸下**（地面先出現紅圈）。
  - Neid：迴旋斬；踢飛加空中斬；**瞬移 7 連斬**（Gerard 會喊「散開」）。
- **記憶點**：雙 Boss 的人格衝突就是機制本身，非常巧妙。抱怨：旋風斬鎖定追蹤沒有解法；Boss 偶爾卡進牆角。
- 💡 **原創構想「錘與針」**：一高瘦、一矮壯的雙 Boss，兩人之間有**能量繫帶**，穿過繫帶會受傷。血量差距過大時較弱的一方狂暴。**由兩名玩家各自拉開仇恨**，必須事先設計好單人時的解法（例如場地中有誘餌裝置）。

- 💡 **原創構想「模組蠻兵」**：在閾值時**身體部件變形**，看到新武器就知道它換招了，等於視覺上的階段預告。給予明確的「過熱散熱」破綻窗口。

### 3.19 Crono Wing／Kronobotics 54（台：瑪瑟爾，新聞稱「災厄天使瑪瑟爾」）— S5 Last Ride
- **外觀**：嬌小的女性飛行超級士兵，有翼形噴射背包，**除非被擊敗，否則不會降落**。叫聲像鷹身女妖。台詞中一直稱讚 Douglas。
- **HP**：普通難度約 **1,500K**。**翅膀和翅膀後的飛彈艙**受到的傷害較高。
- **招式**：機槍連射（鎖定一人）、**追蹤飛彈**（**可以被射下**）、加速、**一字型轟炸**（喊出台詞後沿一條線用飛彈或機槍掃過）。
- **場地**：Map 1 在直升機上防守，對付她和無人機群。Map 3 在管制塔上決戰。
- 💡 **原創構想「掠空獵鷹」**：載具防守加空中掃射，掃射路線用**地面紅線**預告，弱點在引擎。高傷害的狙擊型武器在這場有明確的發揮空間。

### 3.20 Mr. X（MX-2000 → 變異體）— S6 Episode Choi
- **第一階段（MX-2000 機甲）**：
  - 雙槍朝下亂掃（貼近機甲有死角）。
  - **有人貼身就發動 360° 迴轉雷射**（即死）。
  - 雙雷射交叉成 X 字，由下往上掃。
  - **燒夷彈**：地上留下火焰區，每秒 50 傷害。
  - **HP ≤ 50% 時「暴走程序」啟動**：移速與出招速度 +50%。
- **轉場**：機甲被打壞後，地面 7 個人孔蓋閃紅光然後炸開（站在上面掉進毒池會死，May 會預警）。Mr. X **跳進毒池變成巨大章魚怪**。

- 💡 **原創構想**：「**駕駛彈出後異變**」的兩段式戰鬥，加上**打地鼠式**的多洞口第二階段。地形在轉場時改變，可以讓第二階段像一場新的戰鬥。

### 3.21 Condemned Criminal／Bootleg — S6 Episode Victor
- **外觀**：電鋸殺人魔風格的變異囚犯，穿 Vanguard 製的**模組化裝甲**。
- **核心機制（部件破壞）**：

  | 部件 | 功能 |
  |---|---|
  | 頭盔 | 雷射鎖定多名玩家後砲擊 |
  | 電鋸 | 單人連打；被鎖鏈綁住時會被打到死 |
  | 砲彈 | 大範圍拋擲藍色炸彈 |
  | 胸甲 | 蓄能後爆炸或全場暈眩（特效一樣，看不出是哪一種），之後隱身 |
  | 噴射腿 | 左右腳分別判定；空中飛踢、地面滑鏟 |

  - **重新著裝**：6 個點位彈出零件箱飛向 Boss。**箱子在飛行途中可以打爆**，或先打掉耐久。
  - 全部部件破壞後，Boss 從地面拔出電鋸。
  - 沒有部件時打太多會觸發「重新著裝」並進入無敵。
- **無裝甲階段**：揮鋸；旋風（近戰與投擲物無效）；**「丟手帕」鎖鏈陣**：嚎叫後用鎖鏈把玩家圍成一圈，接著旋風斬。**蹲下即可免疫**。
- **抱怨**：重新著裝讓戰鬥時間被迫拉長，「傷害再高也打不快」，這是 Victor 章節不受歡迎的原因之一。
- 💡 **原創構想**：部件破壞型 Boss，由**「回收地精」**小怪把零件搬回去，**殺掉地精就能阻止重新著裝**。把拖延時間的機制改成玩家可以主動處理的目標。

### 3.22 Tyrant Crab — S6 Episode Lucia
- **外觀**：Kronos 改造的巨蟹，甲殼硬到能彈開步槍子彈，帶有劇毒。
- **招式**：**毒氣光環**（靠近就持續扣血）；推土機式**直線衝撞**（即死，Lucia 預警太晚）；受到一定傷害後**爬上天花板**，向下**噴毒液**（地上留下有持續傷害並緩速的區域）。
- **反制**：射擊**標示紅三角的腳**讓它掉下來 → 翻肚 → 射擊**胸口**（但它會一直翻動身體）。
- **抱怨**：namu 認為它是除 Colossus 外最難的 Boss。場地小、小怪爆量、困難 9 通關數最少，「不受歡迎的地圖」。
- 💡 **原創構想「巢母」**：倒掛在天花板的蜂巢母體，射斷**錨點**讓它墜落、露出腹部。**限制小怪數量**，並給足迴避空間。

### 3.23 Agent J（台：傑伊）— S6 Episode Carlito
- **外觀**：接近人類的女性刺客型超級士兵，雙持大型 Uzi 和兩把短刀，**體型小**（HP 較低作為補償）。
- **招式**：短刀揮砍；**突進斬**；翻滾閃避；**左右移動掃射**；**爬到場外路燈上掃射**（路燈方向有死角）；丟手榴彈。
- **背後的 Comanche 直升機（Douglas 駕駛）**：定時發射**可被擊落的追蹤飛彈**；接著發射**無法閃避、無法擊落、射程無限**的火箭（約打掉一半 HP，還有傷害加倍的 Bug）。
- **抱怨**：火箭被 namu 評為「集所有壞設計於一身」的招式。
- 💡 **原創構想**：「敏捷獵手＋支援砲艇」的雙重威脅，但**砲艇的每一招都能躲或能擊落**。可以讓玩家分工：一組打 Boss，一組搶占防空砲。

### 3.24 Colossus — S7 All-Out
- **外觀**：Kronos 的超巨型無人兵器，**偽裝成廢棄大樓**，起身時一擊推倒旁邊的公寓。玩家約 1.8 公尺時，它**超過 160 公尺**；手臂上一個砲口的直徑約是玩家身高的 2 倍。外觀左右完全對稱（被嫌做得草率）。
- **HP**：普通難度 **7,000,000**。
- **招式**：追蹤飛彈（可擊落）；**肩部防空飛彈雨**（數量多又追蹤，只能盡量打下來減少數量）；翼端**大量慢速追蹤雷射**（會互相纏繞，疊加傷害）；**踩踏**（鎖定玩家，被踩到即死）；**無人機群**（發射小砲、會自己回收）；**雙眼聚能火球**（範圍極大，空中可擊爆）；**投下 2 台 XT-300 機甲**（**殺掉駕駛後可以搶來開**，是生存關鍵）。
- **部件**：砲管、飛彈、雷射艙可以分別破壞，冒白煙時表示受損，變紅表示快壞了；破壞後該攻擊減弱，例如飛彈減半。
- **場地**：Boss 站在場外，近戰武器碰不到，只能靠射擊。場地呈包圍狀，沒有地方躲。有專屬主題曲。
- 💡 **原創構想「天際線泰坦」**：超巨型步行要塞。**破壞肢體上的武器艙來關掉招式**，空投的載具或砲塔**可以被玩家奪取**。最終一擊可以做成全隊合作的 QTE（手機上的大按鈕）。

### 3.25 Megalodon／MegaTeeth（메가티스）— S7 Rendezvous
- **外觀**：Kronos 用生化改造的殭屍鯊，部分機械化，原本是海盜 Michaela 的寵物。
- **招式**：在水中停頓後**跳上平台咬人**（看它面對的方向，往旁邊閃）；側躺在水面**吐出會自爆的水母**（水母慢慢追人）；**大跳橫掃平台**後落回水中（被擊落到水裡時，若有水母在附近會被炸死）。
- **場地**：第一次遭遇時要搶時間破壞水道牆上的結構、關門逃走（兩側通道同時重生是設計缺陷）。決戰在水道和平台上。
- **抗性道具**（舊制）：對抗它的破地、衝刺、炸彈技能，在困難 3、6 以上生效。
- 💡 **原創構想「運河潛行者」**：鰻類的輪廓（不用鯊魚）。在水中時以**水面的 V 形水紋**預告位置，派出的漂浮水雷可以被引爆、反過來炸到 Boss。

### 3.26 Security System's Robot — S7 Rex Labs
- **HP**：普通難度 **8,000,000**。
- **P1（固定在中央）**：追蹤火球、**旋轉雷射牆**、定點飛彈、**由內往外擴散的衝擊波環**、**全場落雷**（站進地上標示的**方形安全區**就能躲）。
- **P2（50% 後開始移動）**：瞄準雷射、寬幅砲擊、追蹤火球、飛彈；**致命落雷**：30 秒內破壞剛出現的**發電機**，Boss 就會**暈眩並降低防禦**，失敗則全員被一擊殺死。
- **評價**：體型大、HP 多，但前搖很長，namu 認為「容易破解」。
- 💡 **原創構想**：手機版的「輕量彈幕」Boss。安全格子加上「限時破壞發電機換取破綻」，是**很適合手機的讀招玩法**。

### 3.27 Agent B — S7 Lowdown（並常被當作中頭目）
- **外觀**：炸彈專家型超級士兵（像 Overwatch 的 Junkrat）。
- **招式**：直線爆炸拳；砸地範圍爆炸；拋擲炸彈（落點先出現**紅色預警**）；連續爆炸的滾動炸彈；**在指定平台裝 C4 準備炸掉它（可以拆除）**；衝到中央狂丟炸彈；擊退力很強的地雷。
- 💡 **原創構想「拆遷師」**：會改變場地的 Boss。玩家**拆除炸藥可以獲得全隊增益**，炸掉的平台會改變後半段的戰場。

### 3.28 Agent H — S8 Upcoming Threat（兩次遭遇）
- **第一次**：裝著 4 條機械腿。近距離連發爆炸彈、廣域炸射、突進重擊。
- **第二次**：能量斬；蓄力衝撞；地面電場；**升空後發射追蹤飛彈，被鎖定的玩家頭上出現箭頭**；落地重擊；**受到太多傷害時自動張開緊急護盾**；追擊連斬。
- 💡 **借鏡**：「**被鎖定者頭上的箭頭**」對手機玩家非常友善，建議納入我們的通用標示系統。

### 3.29 Hippomenes — S8 Neon City
- **外觀**：Kronos 用**獅子**改造的人造生物，有火焰能力。
- **招式**：跳躍重擊（落點留下一排火柱）、衝鋒、火焰吐息（距離遠時附加緩速）、爪擊、旋轉火浪（把人打上天）、**詛咒火球**（趴下、鬃毛發光後，生成追擊一人的火球）。
- **50%**：張開護盾進入無敵，召喚 4 顆**地獄火球**往 Boss 移動。**打碎火球會在原地留下安全區**；火球全部抵達 Boss 或被打碎後，Boss 打破護盾，**沒有站在安全區內的人全部死亡**。
- **瀕死**：毛色轉綠，張開維生護盾。
- 💡 **原創構想「稜鏡獸」**：「打碎飛行物產生安全區」的**團隊目標分配**。手機上要把目標標得清楚，並顯示安全區的倒數。

### 3.30 Narak — S8 Abandoned Hound
- **外觀**：Kronos 製的**巨大機械化蠕蟲**，帶著多條附屬尾巴。
- **本體招式**：**束縛吞食**（把正前方的玩家拉進嘴裡，打出足夠傷害才會停）；身體發藍光後**全身放電**；地面橫掃；吐 3 發毒彈；**鑽地撤退**（前方出現黑色標示，站在上面會被吞）；**毒吐息**（嘴裡累積毒球，必須啟動場上的 **H.C 加農砲**打斷它，進入破綻狀態；失敗則全場即死）；**破土而出**（把玩家吸往出土點）。
- **尾巴招式**：射出 3 根尖刺；地刺把人頂上天。打尾巴也會扣本體的 HP，但最後一擊必須打在本體上。
- 💡 **原創構想**：繞著場地外圈移動的**列車狀百足蟲**，用場地上的加農砲打斷大招。輪廓要避開常見的沙蟲造型。

### 3.31 Asterios — S8 Overflow
- **外觀**：Kronos 結合異界科技的超級士兵，雙持戰斧，像牛頭人（推測），會**穿越次元**。肩甲可以打碎。
- **招式**：揮斧（範圍很大，站在背後也會被砍到）；嚎叫後佈置炸彈，留下燃燒地塊；衝鋒（附加緩速）。
  - **50%**：隱身，開啟 2 個傳送門並來回衝刺。
  - **30%**：跳開後召喚大量**幻影分身**砸地。**藍色標示是分身，紅色標示是本體**。
- 💡 **借鏡**：分身與本體用「**地面標示顏色**」區分，非常直覺。原創版可以做「鏡像分身」，並同時用顏色和形狀區分（照顧色盲）。

### 3.32 Agent C — S9 Obstacle
- **外觀**：全身紅色裝甲，拿盾牌和手持機槍（像 Metal Arena 的坦克型角色），自戀。
- **招式**：盾擊、機槍掃射（命中緩速）、電網陷阱、天降炸彈（留下燃燒緩速區）、緩慢追蹤的導引炸彈。
  - **70%**：跳到中央，裝甲加熱進入無敵，釋放熱浪。
  - **超防禦機制**：張開屏障後完全不動，用 **綠 → 橙 → 紅** 表示屏障狀態，玩家要把屏障打破。失敗會**引爆熱浪全場即死**，此時可以啟動 4 台**無線電**之一張開防護罩來擋。
- 💡 **借鏡**：「**輸出檢定＋失敗後還有團隊補救**」的雙保險，比一次失敗就團滅友善。

### 3.33 Mammon — S9 Secret Plan／Chaser
- **外觀**：笨拙的大塊頭（像 Doom 的 Mancubus），用火焰噴射器和噴射背包，會說話但口齒不清。在 Secret Plan 被打到 0 HP 時**逃走**，在 Chaser 才真正死亡。
- **招式**：**180° 火焰噴射**（發射前有**兩聲「喀鏘」聲**）；旋轉噴火；衝到角落後向空中噴火（噴射背包的落火留下燃燒地塊）；衝到角落後把炸藥拋到對面；**燃料罐**：跳到安全點，隨機放下 2 個燃料罐，之後跳下來爆炸，**沒打掉的燃料罐也會爆**。
- 💡 **借鏡**：**聲音預兆**（兩聲喀鏘）。手機上要同時配合**震動回饋**和**畫面圖示**，因為很多人玩手遊時關聲音。

### 3.34 Dominus — S9 Chaser
- **外觀**：自大的飛行超級士兵（設計參考 Crono Wing），登場台詞化用凱撒的名言。
- **招式**：跳砸加爆炸；手炮雷射；**60%**：離開戰場，對場地 2 個隨機邊緣轟炸；**50%**：再次離場，對中央進行更大的轟炸；**30%**：飛到中央，橫向發射 2 次寬雷射；觸手（從燃燒地塊竄出，被打中的人**不能切換武器**）。
- 💡 **借鏡**：**HP 閾值觸發腳本大招**（離場轟炸），節奏清楚，玩家看得出「快贏了」。

### 3.35 Adamant／Adamant-Z — S9 No Way Out（全系列最終 Boss）
- **外觀**：Douglas Jacob 的高科技機甲，裝備機槍、飛彈和熱能刀。第一具其實由 AI 控制，駕駛艙裡的 Douglas 是全息影像。
- **招式**：180° 機槍掃射；雷射飛彈；**落雷區**（天花板出現雷擊範圍，隨機爆炸）；原地旋轉掃射並用刀擊退；2 連斬；**連續 4 次衝刺，留下爆炸軌跡**；**背後持續噴火**，防止玩家繞背近戰。
- **Adamant-Z**：注入病毒的版本，HP 更高，**HP 歸零時復活 2 次**，依靠場上的**能量傳輸裝置**回復。劇情中 Carlito 自爆破壞了這些裝置。
- **抱怨**：Fandom 記載它被大量批評「機制重用、HP 太厚」。主題曲有一段合唱，歌詞是要 Douglas 出來決戰。
- 💡 **教訓**：最終 Boss 必須**有新東西**。「復活」要有玩家能**事先破壞的來源**，並在畫面上清楚顯示剩餘次數。

### 3.36 活動 Boss：Teddy Terror（棒槌熊）／Light Zombie Boss（莎拉BOSS）
- **Teddy Terror**：穿著 Elite Crew 服裝的泰迪熊，拿玩具槌。用玩具版重現舊 Boss 的招式：棒棒糖從地面竄出（等同觸手）、哼歌後全場變暗加上黑洞吸引再迴旋。P2 時**摘下墨鏡**，新增滑行衝刺（預兆很大）。使用火焰風暴時會掉補給箱。
- **Light Zombie Boss**：Q 版可愛的 Light 殭屍，抱著一顆殭屍手雷。招式有踩踏、害羞隱身、騎著手雷跳躍、丟出**會追人咬人的手雷寶寶**；連續狂丟手雷後**自己暈倒**（破綻），也有被手雷砸到頭的搞笑招式。
- 💡 **借鏡**：用**季節性搞笑換皮**快速做出活動內容，成本低，玩家反應好。

### 3.37 其他
- **Armored Titan**（進擊的巨人聯動）：玩家用立體機動裝置攀上巨人，攻擊後頸弱點，巨人會用手拍後頸防禦。這是「**攀爬巨大 Boss**」的設計參考。

## 4. Boss 為何令人難忘，玩家又抱怨什麼

### 4.1 記憶點
1. **登場演出（cinematic intro）**：
   - Kraken 觸手打塌地板，連 AMP Suit 一起掉下去
   - Colossus 從偽裝的大樓中站起來，推倒公寓
   - Revenant 擊落直升機後暖身
   - Angra 破繭而出、大樓爆破
   - Laser Wing、Jack 有專屬過場
   - 第二隻 AMP Suit 擄走 NPC
2. **語音預警與台詞**：Soy、Jim、Gerard 等的無線電把預兆「說出來」；S4 之後的 Boss 會嘲諷、自我介紹（Neid 和 Zavist、Rex、Crono Wing 對 Douglas 的崇拜）。
3. **場地機關讓全隊分工**：
   - 閥門（Revenant）、雙雷達同步（Angra）
   - 氣體管通往高架（Gluttony）、排毒管（Jack）
   - C4（Kraken、Gluttony）、H.C 加農砲（Narak）
   - 無線電防護罩（Agent C）、安全格子與發電機（Security Robot）
   - 打碎火球製造安全區（Hippomenes）、可搶奪的機甲（Colossus）
4. **階段變化有視覺標記**：Oberon 長爪、Revenant 起火、Crono Athletic 手臂炸成武器、Mr. X 從機甲變成章魚、Kraken 三形態、Rex 從人類變成怪物、Hippomenes 毛色轉綠。
5. **跨章節宿敵**：Dione → Siege Dione → Angra；Mammon 第一次逃走、下一章才死；Jack 和 Jennifer 的恩怨。
6. **Boss Rush 模式**（殲滅：極限生死戰等）把整季的 Boss 重新打一遍，是長期遊玩的目標。
7. **專屬 Boss 主題曲**（Colossus、Narak、Asterios、Adamant 的合唱等），以及章節固定的「生存音樂／追蹤與 Boss 音樂」分層。
8. **擊殺獎勵與造型掛鉤**：Oberon 角、Angra 翅膀、Titan 玩偶等劇情裝飾，曾經附帶屬性加成，後來轉換成 Add-on。

## 5. 給我們手機 co-op 割草射擊的設計總結

### 5.1 敵人生態（雜兵）建議配置
| 職能 | 數量比例（推測） | 對玩家的要求 | 手機調整 |
|---|---|---|---|
| 基礎兵 Shambler | 60% | 清場 | 容易被自動瞄準 |
| 衝刺兵 Skitter | 15% | 走位與優先擊殺 | 低姿態但不隱身 |
| 坦克 Barrel | 8% | 集火 | 死亡留下緩速區 |
| 補師 Nurse Sac | 3% | 切後排 | 可見光束 |
| 遮蔽 Fogger | 3% | 走出霧區 | 霧區邊界清楚 |
| 長手 Lancer | 4% | 側閃 | 直線預警 |
| 自爆 Bloater | 4% | 保持距離，或爆頭讓它不爆 | 膨脹倒數 |
| 群鼠 Rat Pack | 間歇波次 | 範圍武器 | 低矮目標的瞄準輔助 |
| 遠程 Bottler | 3% | 移動 | 落點圓圈，不晃準星 |

### 5.2 Boss 預兆語言（統一規範）
- **地面標示**：紅色＝真正的危險，藍色／灰色＝假的或安全；顯示形狀和**填滿倒數**。
- **被鎖定提示**：被鎖定者頭上出現箭頭（借鏡 Agent H），同時手機震動。
- **語音與文字橫幅**：NPC 喊出 Boss 的下一招（借鏡 Soy），並配合畫面上的圖示（很多人玩手遊時關聲音）。
- **前搖時間**：高傷害招式的前搖至少 0.8–1.2 秒，並配合翻滾無敵幀。
- **禁止**：穿牆命中、範圍無限、無法擊落又無法閃避的攻擊（Agent J 火箭和 Kraken 雷射是反面教材）。

### 5.3 機制替換表（避免 CSO 最被嫌的設計）
| CSO 機制 | 問題 | 我們的替代方案 |
|---|---|---|
| 繳械掉武器 | 手機撿武器很痛苦 | 卡彈或過熱 1.5 秒；或強制換到副武器 |
| 即死 | 挫折、拖慢節奏 | 倒地，隊友可以救；單人時給自救次數 |
| 長時間無敵 | 拖戰 | 無敵最多 5 秒；或有可打破的護盾條 |
| Boss 回血 | 拖戰 | 回血來源看得見、打得掉（光束、營養管、地精） |
| 雙人同步機關 | 路人房容易失敗 | 單人時改成單點啟動加較長時間；或由 AI 隊友代勞 |
| 蹲下躲招 | 手機上沒有方便的蹲鍵 | 翻滾，或站到安全格子 |
| HP 堆量 | 火力通膨 | 用**輸出檢定窗口**與**部件破壞**代替純 HP；依人數與難度縮放 HP |

### 5.4 階段設計模板
- **100 → 70%**：基本招式＋小怪。
- **70%**：第一個機關事件（例如閥門、雷達）或場地變化。
- **50%**：外觀改變加上新招（狂暴），**弱點更容易打到**作為補償（借鏡 Angra 受到的傷害×2）。
- **30%**：腳本大招（離場轟炸、分身），中間給全隊一個輸出窗口。
- **擊殺**：短過場加上掉寶。若要讓 Boss「逃走並在下一章再出現」，需要劇情鋪陳。

### 5.5 剪影（silhouette）區隔原則
- 每個敵人在 **64px 黑影**下要能辨認，並且和 CSO 原作明顯不同。避免：獨眼肥胖巨人、六眼魚頭爬蟲、人形蚱蜢、雪人加冰棍、蠍子裝甲車、章魚機甲駕駛等 CSO 的標誌造型。
- 變體要同時用**顏色和小配件**區分（頭盔、背包、光環），不能只靠換色。
- Boss 的輪廓尺度要分級：人形大小（敏捷型）→ 3–5 公尺（標準）→ 場地級（Kraken、Colossus 類，需要專屬場景）。

## 7. 不確定事項（⚠️）
1. 雜兵的 HP 與速度只有**相對等級**，速度參考的是「可遊玩殭屍」的數值，劇情模式 NPC 的實際數值未公開。
2. Boss HP 只有部分數字（Revenant、AMP Suit、Kraken、Crono Wing、Neid 和 Zavist、Juggernaut、Ganymede、Colossus、Security Robot），而且有些是困難 9 或普通難度的玩家實測，可能已被 2026 年平衡測試改動。
3. Revenant 有沒有弱點，Fandom（胸口王冠）和 namu（無弱點）說法不同。
4. Gluttony 胃中需要的 C4 數量：Fandom 說 3 顆，namu 只說安放 C4。
5. Neon City 的 Boss：Fandom 季別頁寫「Behemoth」，個別頁面和 namu 都是 Hippomenes，以後者為準。
6. 台服 Ganymede、Phobos 的譯名，是從繁中 Wiki 的回合列表推斷的；S6 之後的台服譯名都未查證。
7. Steam 玩家抱怨（普通難度超過 100 萬 HP、Boss 優先打我）來自搜尋工具的摘要，原文頁面沒有成功讀取。
8. 「Gargantua」在 CSO 殭屍劇情中查無此 Boss。
9. 「황금 좀비」（黃金殭屍）只知道擊殺可獲得特定獎勵（例如 Sonya 角色），namu 該段內容空白。
