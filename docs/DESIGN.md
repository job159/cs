# 災厄前線 CALAMITY FRONT — 設計總綱

> 1–4 人合作的回合制殭屍防禦 FPS（Android WebView + 瀏覽器）。玩法仿 CSO「殭屍劇本／災厄之章」，畫面走 CS2／PUBG 寫實風，
> 武器再加上 CSO 近年「克金」武器的華麗演出。所有名稱、造型皆為原創（只借機制與幻想）。
> 調研：`docs/research/01–05`；武器建模規範：`docs/WEAPON_MODELING.md`；高階武器規格：`docs/PREMIUM_WEAPONS.md`（v1.0 定案：24 把名冊、克金設計語言、塗裝系統、實作順序）。

## 1. 需求審視與改良決策

| 使用者需求 | 決策 | 理由 |
|---|---|---|
| 模仿 CSO 災厄之章、回合制大量殭屍 | 一張大地圖、10 回合＋最終 BOSS 的「章節」，回合在地圖各區推進（防守→推進→裝置→BOSS） | CSO 現代劇本以推進＋裝置＋BOSS 最受歡迎；純生存 50 回合太冗長（官方已縮短） |
| 1–4 人房間 | 主機權威，WebRTC 點對點＋MQTT 中繼備援；公開房間列表＋房號；**人數不足可補 AI 隊友** | 單人也有團隊感 |
| 武器質感、攻擊手感最重要 | 程序化寫實建模＋烘焙 AO／邊緣磨損＋三平面細節法線；IK 手臂＋關鍵影格換彈；彈簧後座、槍口火光照明、曳光、拋殼、彈孔、擊中停頓、觸覺回饋；真實槍聲錄音分層 | 見研究 03 第 4 章 |
| 殭屍質量 | CC0 寫實人體（MakeHuman）＋殭屍皮膚＋撕裂衣物；遊戲骨架＋動作捕捉動畫；命中部位反應、斷肢、爆頭、布娃娃死亡、血跡貼花 | 寫實風需要真人比例與動作 |
| CS / PUBG 風格 | 照片掃描 PBR 材質（Poly Haven）、HDRI 天空光、即時陰影、霧與體積光、寫實調色 | 使用者中途指定 |
| 克金武器 | 稀有度四階＋CSO 式華麗特武（變形、召喚、擊殺特效、專屬準星）＋CS2 式稀有塗裝（漸變、多普勒、表面淬火…） | 使用者中途指定 |
| 防具 | 防彈衣（減傷＋耐久）、頭盔（防抓擊晃動）、主動鱗甲（危機格擋） | 研究 03 §3.1 |

## 2. 一局的流程（第一張地圖：失落之城）

使用者指定「地圖盡可能模仿 CS 經典災厄之章的地圖」，因此第一張地圖以第 1 季經典生存圖**失落的城市（Lost City）**為藍本重建：
被病毒封鎖的北美工業小鎮、十字形街區、中央路口防守、殭屍從四面八方湧入。佈局、地標與動線依參考畫面忠實重現；
所有模型、材質與光影由我們自行製作（不拆取原遊戲檔案），地圖名稱暫定「失落之城 LOST TOWN」。
細節（尺寸、地標、出怪點、購買區、補給點）見 `docs/MAP_LOSTTOWN.md`（地圖調研後產出）。

| 回合 | 內容 |
|---|---|
| 1–4 | 生存：殭屍從十字街四個方向湧入，逐回合加入狂奔者、噴吐者、爆裂者、爬牆者、尖嘯者、防暴屍 |
| 5 | 中 BOSS 回合（巨型重裝屍）＋殭屍群 |
| 6–9 | 生存：精英變種與混合群，屋頂／小巷側襲 |
| 10 | 最終 BOSS（多階段）＋殭屍群 |

- 每回合約 2–3 分鐘或清空殭屍即結束；回合間 20 秒購買時間；場上補給箱（彈藥／護甲／隨機特武）。
- 局內成長（CSO 風）：擊殺與 BOSS 傷害給經驗 → 升級時選「攻擊／生命／換彈／移速／擊退」其一（預設自動）。
- 倒地與救援：血量歸零先倒地 20 秒，隊友長按救起；單人有 2 次腎上腺素自救；回合結束全員復活；全滅可重試該回合（次數依難度）。
- 難度：普通／困難／地獄／災厄（血量與傷害倍率、精英詞綴）。
- 金錢：擊殺、爆頭、助攻、回合獎勵；局內購買武器與護甲。局外：帳號等級解鎖高階武器與塗裝（不涉及真錢）。

## 3. 敵人

一般：行屍（多種外觀）、狂奔者、重裝屠夫、酸液噴吐者、爆裂者、爬牆者、尖嘯者（治療／增益）、防暴屍（前方護甲）、屍犬、精英變種（顏色＋詞綴）。
BOSS：屠宰者、夜魘、深淵巨獸 — 各有階段轉換、地面預警、可閃避的大招、場地機關（研究 02 的建議：不用繳械、不用秒殺）。

## 4. 技術架構

- three.js（WebGL2）＋ esbuild，Android 用無 Gradle 的 WebView 外殼（沿用霓虹防線流程）。
- 渲染：HDR MSAA → 雙重濾波泛光 → ACES＋調色；動態解析度；畫質四段（低／中／高／極致）。
- 第一人稱：槍與手臂在真實場景中（吃到真實光影），用專屬投影＋深度壓縮避免穿牆。
- 資產：武器與手臂由 `tools/assets` 程序化建模並烘焙 → GLB；殭屍由 MakeHuman CC0 資產轉檔；場景用 Poly Haven CC0 材質。
- 連線：`game/src/net/`（WebRTC＋MQTT），主機模擬殭屍，客戶端插值；命中由開火方判定後送主機確認。
